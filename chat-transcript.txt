### User

Build a complete Spectacles Lens: a calligraphy tutor that teaches the user to write the letters A, B, C.

Scene setup
One panel in world space, positioned about 50cm in front of the user at chest height, facing them, roughly 40cm wide. Inside it, two rectangular slates side by side with a small gap. Left slate = "Learn box", right slate = "Practice box". Both slates have four horizontal ruled lines: ascender (top), midline (dashed), baseline, descender (faint). Capital letters are drawn between the ascender and baseline lines.

Above the slates: a row of step pills, one per stroke of the current letter, each showing a number badge and a short instruction. The current step is highlighted; all steps stay visible. A small label top-left shows the current letter, and top-right shows the attempt state.

Below the Learn box: buttons replay, prev, next. Below the Practice box: undo, erase, done.

Letter data
Store each letter as an ordered list of strokes. Each stroke has: an id, a list of points in normalised 0–1 coordinates (0,0 = top-left of the letter box at the ascender line, 1,1 = bottom-right at the baseline), and a hint string. Use exactly this data:

A, 3 strokes:
1. points [0.5,0.0] to [0.1,1.0], hint "left diagonal, top to bottom"
2. points [0.5,0.0] to [0.9,1.0], hint "right diagonal, same start"
3. points [0.22,0.65] to [0.78,0.65], hint "crossbar, left to right"

B, 3 strokes:
1. points [0.15,0.0] to [0.15,1.0], hint "stem, straight down"
2. points [0.15,0.0], [0.60,0.05], [0.72,0.25], [0.60,0.45], [0.15,0.50], hint "upper bowl, curve out and back"
3. points [0.15,0.50], [0.65,0.55], [0.80,0.75], [0.65,0.95], [0.15,1.0], hint "lower bowl, wider than the first"

C, 1 stroke:
1. points [0.85,0.15], [0.60,0.0], [0.30,0.05], [0.12,0.30], [0.12,0.70], [0.30,0.95], [0.60,1.0], [0.85,0.85], hint "one curve, top right to bottom right"

This one structure must drive the demo animation, the step pills, the ghost overlay, and the scoring. Do not use font glyphs.

Demo animation
On entering a letter, the Learn box draws it stroke by stroke at natural writing speed, with a visible dot travelling along the path and a short pause between strokes. A numbered badge sits at each stroke's start point. The active step pill highlights in sync. replay plays it again.

Writing input
The user writes in the Practice box by pinching and moving their hand. Project the pinch position onto the Practice box plane. Pinch down begins a new stroke, movement while held appends points, release ends the stroke. Render strokes as uniform-width lines in a distinct colour from the guide.

Scoring
When the number of user strokes equals the letter's stroke count, score automatically. done is a manual fallback.

To score: resample each user stroke to about 20 evenly spaced points. For each point, measure the distance to the nearest point on the corresponding target stroke path. Count it as inside if the distance is under 13% of the letter height. The score is the percentage of points inside, across all strokes.

Then apply three checks: the stroke count must match; each stroke must start within a generous radius of the expected start point; each stroke's start-to-end direction must roughly match the target's direction.
Pass at 70% or above. Be generous — false failures are worse than false passes here.

Ignore any user stroke shorter than 10% of the letter height. If the user's total ink length is far below the target's, show "that one looks incomplete" instead of a score.

Feedback
On scoring, a verdict bar appears across the top strip of the Practice box showing the accuracy percentage and pass / not yet. Below it on the same line, one short diagnostic in plain words naming the single biggest problem — for example "crossbar sits too high", "right diagonal drifted outward", "left diagonal drawn upward". Derive it from whichever check scored worst.

At the same time, overlay the target letter on the user's strokes as a dashed ghost so the difference is visible.
The button row under the Practice box swaps in place to try again and next letter. Nothing else moves.

Behaviour rules
- undo removes only the last stroke. erase clears the whole slate, and one press of undo afterwards restores what erase removed.
- done, undo and erase are disabled when the slate is empty. replay is disabled while the animation is playing.
- replay does not clear the user's strokes.
- The slate clears on next, prev, try again and erase. Feedback clears whenever the slate clears.
- prev and next wrap around, so next on C returns to A.
- Erasing only ever affects the user's ink, never the ruled lines, the ghost, or the example.

Guidance ladder
Each letter has a guidance level from 1 to 3, stored per letter, starting at 1. It only changes what the Practice box renders:
- Level 1: a thick faint ghost of the whole target letter, plus a numbered badge at the first stroke's start.
- Level 2: no ghost, only a pulsing dot at the start point of the current stroke.
- Level 3: nothing — an empty ruled slate.

Passing raises the level by one, up to 3. Failing lowers it by one, down to 1.

Do not add
No setup screen, no handedness options, no flat-surface anchoring, no letters beyond A, B and C.

When done, verify
1. The lens opens directly on letter A with the animation playing — no menu.
2. All three letters animate correctly and next wraps from C back to A.
3. Pinch drawing produces visible strokes in the Practice box.
4. A deliberately sloppy but correct letter passes; a wrong-shaped one fails.
5. The verdict bar and dashed ghost both appear on the Practice box after scoring.
6. undo removes one stroke, erase clears all, and undo after erase restores.
7. Passing a letter twice takes its Practice box from ghost, to dot, to empty.
